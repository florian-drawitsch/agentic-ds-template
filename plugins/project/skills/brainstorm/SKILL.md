# Brainstorm

This skill is an alias for `superpowers:brainstorming`.

Follow the instructions in the `superpowers:brainstorming` skill.

A brainstorm does not authorize implementation or delivery. Leave implementation files and
delivery runs unchanged. When the result moves on to a plan, copy the decisions it needs into
the plan, so another session or app can continue without this conversation.
